ROS & Multi-Agent Systems

Synchronization & Coordination of Mobile Robots

A multi-agent exploration system on TurtleBot3, combining frontier-based exploration with gmapping SLAM and live map merging.

Overview

This project focuses on the development and simulation of a multi-agent robot system designed for autonomous exploration and coordination within a shared environment. The system utilizes the open-source TurtleBot 3 robot platform and ROS (Robot Operating System) packages to implement coordinated navigation, obstacle avoidance, and task allocation strategies. The project demonstrates effective autonomous navigation algorithms, simultaneous multi agent exploration and dynamically merged maps.

Project Objectives

  • Implement frontier-based exploration for autonomous environment mapping
  • Deploy SLAM (Simultaneous Localization and Mapping) using the gmapping package
  • Enable multi-robot coordination for simultaneous exploration
  • Develop map merging algorithms to combine individual robot maps
  • Simulate and validate multi-agent exploration in Gazebo
  • Optimize exploration efficiency through coordinated frontier selection

System Architecture

The system utilizes TurtleBot3 Burger robots equipped with LiDAR sensors for environment perception. Each robot runs an independent SLAM node using the gmapping package to build local occupancy grid maps. The frontier-based exploration algorithm identifies unexplored boundaries in the map and guides robots to these regions for autonomous discovery. A central coordination node manages map merging, combining individual robot maps into a unified global map that represents the complete explored environment. The ROS navigation stack handles path planning and obstacle avoidance for safe autonomous movement.

Implementation Details

The frontier-based exploration algorithm analyzes occupancy grid maps to identify boundaries between explored and unexplored regions (frontiers). Each robot independently selects the nearest accessible frontier and navigates to it using the ROS navigation stack. As robots explore, they continuously update their local maps using LiDAR sensor data and the gmapping SLAM algorithm. The map merging node subscribes to individual robot map topics, aligns them using feature matching or odometry data, and publishes a unified global map. This approach enables efficient parallel exploration where multiple robots simultaneously discover different areas of the environment, significantly reducing total exploration time compared to single-robot approaches.

Technologies Used

  • ROS Noetic (Robot Operating System)
  • TurtleBot3 Burger platform with LiDAR sensor
  • Gazebo simulator for multi-robot simulation
  • gmapping package for SLAM implementation
  • ROS navigation stack (move_base, AMCL)
  • Python for exploration and coordination logic
  • RViz for real-time visualization
  • map_merge package for combining robot maps

Results

The multi-robot exploration system was successfully tested in Gazebo simulation environments. Multiple TurtleBot3 Burger robots autonomously explored unknown spaces, building accurate occupancy grid maps using gmapping. The frontier-based algorithm effectively guided robots to unexplored regions, ensuring comprehensive coverage of the environment. The map merging functionality successfully combined individual robot maps into a coherent global representation, demonstrating effective information sharing between agents. Exploration efficiency significantly improved with multiple robots compared to single-robot scenarios, with exploration time decreasing proportionally to the number of deployed robots. The system maintained stable SLAM performance throughout extended exploration missions, producing high-quality maps suitable for navigation and path planning.
